## 📌 Project Overview

The Critical Injury (CI) Dashboard is an interactive Power BI solution developed to analyze workplace critical injury patterns across Ontario.

The dashboard brings together multiple data sources to provide insights into injury trends, regional differences, industry-specific risks, and injury characteristics.

Its primary purpose is to support **evidence-based decision-making, identify areas of concern, and inform workplace injury prevention strategies**.

## 🎯 Project Objectives

- Monitor critical injury trends and changes over time.
- Identify high-risk industries, sectors, and regions.
- Compare injury counts and workforce-adjusted rates.
- Explore seasonal patterns and injury characteristics.
- Support data-driven decisions and resource prioritization.

## 📊 Analytical Scope

The dashboard covers five key analytical areas:

| Analysis Area | Description |
|---|---|
| **Executive Overview** | Key performance indicators and summary insights |
| **Trend & Temporal Analysis** | Historical trends, YoY changes, and seasonality |
| **Regional Analysis** | Geographic patterns and regional comparisons |
| **Industry & Program Analysis** | Injury counts and rates across sectors and programs |
| **Injury Characteristics** | Analysis of injury-related factors and demographic patterns |

## 🛠️ Tools & Technologies
